# AGENTS.md

- This project is the user's personal website.
- Work only on the `gh-pages` branch.
- The website is static, one page, critically minimalistic, and unique.
- Use only HTML, CSS, and a little JavaScript.
- Commit in logical working chunks, with a short one-line lowercase message that describes the goal. Example: "add links to projects", "fix css issue", "cleanup".

## style

- One page, sparse copy, no portfolio-template sections.
- Copy: short sentences only; no slogans, marketing language, or filler.
- Links inline with text; no buttons, cards, badges, grids, or CTAs.
- Layout with whitespace, max-width, line-height, and alignment; no panels, shadows, or decorative containers.
- Palette: neutral background/text plus at most one muted accent for links or hover states.
- JavaScript only for a small optional enhancement; the page must work without it.
